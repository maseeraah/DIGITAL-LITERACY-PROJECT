# DIGITAL-LITERACY-PROJECT

#PROJECT OVERVIEW 
This project highlights key aspects of digital literacy for college students, including hands‑on training, portfolio building, programming, communication etiquette, and awareness of cybercrimes.
It combines practical activities, quizzes, and documentation to strengthen responsible digital practices.

#MODULE SUMMARIES
## 1. Hands‑on Training on Presentation Software
- Practical use of tools like PowerPoint, Google Slides, and Canva  
- Designing effective, professional presentations  
- Applying visual communication principles  

## 2. Building a Digital Portfolio
- Creating an online portfolio to showcase academic and professional achievements  
- Using platforms like LinkedIn, GitHub, or personal websites  
- Highlighting skills, projects, and certifications  

## 3. Programming Platforms & Collaborative Learning Platforms
- Introduction to Python, C, or Java basics  
- Using GitHub and online IDEs for collaborative coding  
- Leveraging platforms like Google Classroom, Moodle, or Microsoft Teams for teamwork  

## 4. Email Etiquette & Basics of Social Media Etiquette
- Writing professional emails (subject lines, greetings, closings)  
- Avoiding common mistakes in email communication  
- Responsible use of social media: Do’s and Don’ts checklist  

## 5. Awareness on Cybercrimes & Financial Fraudulent Activities
- Understanding phishing, vishing, smishing, and spear phishing  
- Identifying man‑in‑the‑middle attacks and fraud schemes  
- Safe online banking practices and digital payment security
